# Architecture decision records

Each significant decision is recorded here when it is made, in a numbered file such as `0001-short-title.md`.

Technology choices live only in these records. The rest of the documentation describes the system, not the tools used to build it.

## Template

```markdown
# N. Title

- **Status:** Proposed | Accepted | Superseded by N
- **Date:** YYYY-MM-DD

## Context

## Decision

## Consequences
```
